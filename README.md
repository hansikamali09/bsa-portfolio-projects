# Business Systems Analysis Portfolio Projects

Two self-contained projects built to demonstrate core Business Systems
Analyst skills: requirements documentation and data-driven analysis.

## Projects

### [01 — Bank Loan Approval Data Analysis](./01-loan-approval-analysis)
SQL + Excel analysis of loan approval trends across applicant segments
(credit history, property area, education, income, dependents). Includes
a synthetic dataset, 10 SQL queries answering specific business questions,
and a multi-sheet Excel dashboard with charts.

**Skills:** SQL, Excel, segmentation analysis, business insight generation

### [02 — BRD: Instant e-Transfer Limit Increase](./02-brd-mobile-banking-etransfer)
A complete Business Requirements Document for a hypothetical mobile banking
feature — problem statement, objectives, scope, stakeholders, user stories
with Given/When/Then acceptance criteria, non-functional requirements, a
swimlane process-flow diagram, and a risk register.

**Skills:** requirements gathering, user story writing, process mapping,
stakeholder analysis
